# Snake and Ladder Game (C++)

A console-based Snake and Ladder game developed in C++.

## Features
- Player vs Computer
- Random dice rolling
- Snake and ladder mechanics
- Turn-based gameplay
- Winning condition at square 100

## Concepts Used
- Object Oriented Programming
- Classes and Objects
- Random Number Generation
- STL Strings
- Thread and Chrono Libraries

## How to Run

Compile:

g++ main.cpp -o game

Run:

./game
